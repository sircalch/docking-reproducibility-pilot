# Amendment 001: controlled heavy-atom repair for RCSB 1L2S chain A

## Purpose and scope

This amendment permits a narrowly defined repair attempt for the stopped RCSB
1L2S chain-A route. It is limited to producing a *repaired receptor candidate*
for software-compatibility validation. It does not authorize ligand docking,
candidate ranking, or biological interpretation.

## Input

The only input is the selected chain-A protein file generated by
`scripts/extract_rcsb_1l2s_chain_a.py`. Its recorded SHA-256 is
`91a5ce4787d91945ace1719b1a5fd9da9e5d12dd6df6e7e2b4c8f7e9da650309`.

## Repair policy

Use PDBFixer 1.12.0 and OpenMM only as follows:

1. Detect missing residues and record them, then set the missing-residue set to
   empty so that no whole residues are inserted.
2. Reject the run if nonstandard residues are detected in the chain-A protein
   input; do not replace residue identities automatically.
3. Detect and record missing heavy and terminal atoms for existing residues.
4. Add only those atoms through PDBFixer's `addMissingAtoms()` step.
5. Do not add hydrogens, solvent, ions, cofactors, a ligand, force-field
   parameters, energy minimization, molecular dynamics, or manual coordinate
   edits.

The script must emit before/after checksums and a machine-readable list of
detected additions.

## Acceptance criteria

The output is acceptable only if the input checksum matches, no nonstandard
residues were replaced, no complete residues were inserted, PDBFixer completes
without warning promoted to error, and Meeko accepts the repaired receptor
without `--allow_bad_res`. Passing these checks establishes only preparation
compatibility.

## Reporting boundary

The repaired model is computationally completed, not an experimental structure.
It must be described as such in any future report and retained separately from
the RCSB coordinate record.

The current repair failed its Meeko acceptance check and is not accepted for
docking; see
[DEVIATION-004-RCSB-1L2S-REPAIR-VALIDATION.md](DEVIATION-004-RCSB-1L2S-REPAIR-VALIDATION.md).
